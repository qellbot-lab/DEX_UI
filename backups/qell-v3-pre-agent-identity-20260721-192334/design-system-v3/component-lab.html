05 / 05

System States

状态页面是设计系统的一部分。加载、空、失败和完成都必须告诉用户发生了什么以及下一步怎么做。

Loading

正在同步市场

通常在 10 秒内完成。

Empty

还没有模拟记录

选择一个历史事件开始首次验证。

Error

市场数据未连接

检查网络后重新同步数据。

Success

战队已准备就绪

所有风险检查均已通过。
