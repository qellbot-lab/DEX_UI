# 08. Licensing Notes

This package is prepared as an internal frontend art handoff.

## Font Notes

Included fonts:

- Chakra Petch family
- Merkur

Before public deployment, redistribution, or brand-wide rollout, confirm that each font file is licensed for the intended usage:

- Web embedding
- Commercial usage
- Redistribution to contractors or partner teams
- Product bundle inclusion

Chakra Petch is commonly available as an open-source typeface, but teams should still preserve license metadata where required.

Merkur should be verified before external redistribution or production use if its license source is unclear.

## Logo Notes

The included QELL logo SVGs are intended for internal product and brand-system handoff.

Do not publish alternate marks or derivative logos without brand approval.
