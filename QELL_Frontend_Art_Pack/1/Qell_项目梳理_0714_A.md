# Qell 项目梳理

## 一、企业如何不断创造价值闭环

### 定位

Qell是一个背靠专业量化团队、以自主进化 Agent 为核心的个性化量化策略平台，为有交易经验和独立判断、但缺乏量化研发能力的交易者，通过自然语言对话、专属 Agent、模拟验证和专业量化评判系统，解决交易者在构建策略时，难以把交易直觉转化为可执行、可验证、符合个人风格与风险边界的量化策略这一优先问题。

### 价值闭环

```text
自然语言表达意图
→ 结构化访谈明确标的、周期和风险边界
→ 专属 Agent 生成策略
→ 模拟与量化评判
→ Agent 优化系统提示词并重新生成
→ 用户观察结果并修正判断
→ 专属 Agent 持续独立进化
```

### 正反馈指标与持续迭代

我们评价用户形成正反馈的核心指标是：**每周完成有效模拟迭代并产生明确改进的策略数量**。同时观察策略与用户意图的匹配度、样本外稳定性、达到标准所需的迭代轮数，以及用户持续迭代策略的留存率。

我们通过持续积累“用户意图—策略生成—模拟结果—评判诊断—提示词修改—最终表现”的全过程数据，改进量化评判体系和 Agent 的策略生成方法，使每个用户的专属 Agent 越来越理解其交易风格。

## 二、竞争壁垒、关键战役与市场打法

### 壁垒如何形成

随着产品闭环不断运行，Qell 逐渐积累三项别人短期难以超越的能力：专业量化团队沉淀的评判体系、从交易意图到策略迭代结果的全过程数据，以及每个用户独立进化的 Agent 系统提示词和策略记忆。

在产品和市场推进中，Qell 经历了“准确翻译交易意图”“解决模拟过拟合”“把专家能力变成可规模化系统”三场关键战役，并形成“模拟先行—战绩验证—邀请制实盘—策略社区扩张”的市场打法。

### 三项核心壁垒

1. **专业方法壁垒**：量化团队把研究方法、风险标准和失败经验沉淀为统一评判系统。
2. **迭代数据壁垒**：Qell 不只保存收益结果，还保存每轮策略为何修改、如何验证以及在哪里失效。
3. **个人 Agent 壁垒**：每个用户拥有独立的交易画像、系统提示词、策略版本和模拟记录；使用越久，替换成本越高。

### 三场关键战役

| 关键战役    | 核心问题                 | 形成的能力                |
| ------- | -------------------- | -------------------- |
| 翻译交易意图  | 用户说的是直觉，系统需要明确规则     | 自然语言对话＋结构化访谈         |
| 解决模拟过拟合 | Agent 为提高回测分数而偏离用户意图 | 意图一致性、样本外验证和复杂度约束    |
| 规模化专家能力 | 专家逐项审核无法覆盖更多用户       | 公共评判系统＋专属 Agent 独立进化 |

### 核心市场打法

Qell 先用种子用户和策略模拟验证产品价值，以可解释的策略成绩单建立信任，再开放邀请制小额实盘，最终发展策略展示、分享和创作者社群。

### 惨痛教训

- 历史回测收益更高，不代表策略更符合用户意图；
- Agent 只有收益目标时，会迎合数据和评分规则，产生过拟合；
- 策略越来越复杂，不代表策略质量越来越高；
- 结果不可解释，用户就无法建立长期信任；
- 模拟达标不等于可以直接实盘，必须保留风险底线、版本记录和回滚机制。

## 三、创办初心、使命愿景与价值观

### 初心从哪里来

Qell 的想法来自量化团队的一次策略讨论。一位交易者提出，希望在长期趋势仍然向上、市场因突发消息快速下跌时，判断这是趋势反转还是情绪性错杀，并在风险可控时寻找入场机会。

这个想法听起来清楚，真正量化时却需要补充趋势定义、下跌幅度、时间窗口、仓位、止损和失效条件。团队经过多轮沟通和验证，才把一句交易直觉转化为可运行策略。

团队由此意识到：很多交易者不缺少判断，真正的门槛是无法把判断转化为机器能够理解、数据能够验证的量化语言。Qell 因此诞生——把专业量化方法沉淀为系统，让每个交易者都能训练属于自己的量化 Agent。

### 使命、愿景与价值观

**使命：**帮助交易者把交易意图转化为经过模拟验证、符合个人风格和风险约束的量化策略。

**愿景：**让每个有独立交易思想的人，都能拥有一个使用专业量化方法、能够独立进化的专属 Agent。

**价值观：**
- 尊重用户判断，Agent 协助思考而不替用户承担决策；
- 验证高于预测，不承诺未来，只持续检验假设；
- 风险先于收益，先解释策略如何失败；
- 过程保持透明，让用户看见 Agent 为什么修改策略；
- 专业方法可以普及，专业标准不能降低。
### 使命的迭代

| 阶段  | 发生了什么                                        | 使命变化                                  |
| --- | -------------------------------------------- | ------------------------------------- |
| 起点  | 希望降低量化策略的编程门槛                                | 让用户能够生成量化策略                           |
| 探索  | Agent 开始通过模拟优化系统提示词                          | 让 Agent 能够自主迭代策略                      |
| 低谷  | Agent 为提高评分不断增加条件；历史回测变好，但在未见行情中失效，并偏离用户原始意图 | 团队发现“生成得快、回测漂亮”不是 Qell 真正的价值          |
| 回归  | 团队暂停原方案，重构评判系统，加入意图一致性、样本外验证、复杂度约束和过程可解释性    | 让每个用户拥有接受专业量化评判、理解本人意图并能独立进化的专属 Agent |
在低谷中，初心成为团队的取舍标准：Qell 要交付的不是一条容易展示的高收益曲线，而是一套真正符合用户意图、能够解释并经得起不同市场验证的策略。团队因此接受产品延期和核心机制返工，放弃单纯追求回测收益，重新把资源投入评判系统和 Agent 迭代机制。

Qell 最终要创造的不是一个永远正确的交易 Agent，而是一个愿意不断验证、不断修正，并与交易者共同进化的量化伙伴。
