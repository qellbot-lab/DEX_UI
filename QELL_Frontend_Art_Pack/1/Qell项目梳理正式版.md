# Qell AI Trading 项目梳理

**项目名称：** Qell AI Trading  
**版本：** 正式版 V1.2  
**日期：** 2026 年 7 月 14 日

---

## 核心摘要

Qell AI Trading 是一个面向多资产个人交易者的 AI 量化策略平台。Qell 服务于有一定交易经验和自己的操作逻辑，但缺少编程能力、专业量化团队以及稳定执行与复盘能力的进阶个人交易者。

Qell 通过自然语言策略生成、Agent 量化战队、专业量化团队反馈、历史沙盘、实时模拟、风险检查和交易复盘，帮助用户把交易想法逐步转化为符合自身收益目标、风险偏好和交易风格的量化策略。

在这一过程中，专业量化团队提出优化建议，建议被逐步沉淀为 Agent 可以学习和复用的评价规则；交易者则通过观察 Agent 每一轮迭代，更清楚地理解自己的交易风格、市场判断和风险边界。

Qell 的核心价值主张是：

> **Qell 不只帮助交易者生成策略，而是让交易者与 Agent 在持续验证中共同进化。**

# 一、企业如何不断创造价值闭环

## 1.1 我们是谁

我们是 **Qell AI Trading，一个面向多资产个人交易者的 AI 交易决策与量化策略平台**。

Qell 将过去集中在量化机构和专业交易团队中的策略研究、模拟训练、风险控制和交易复盘能力，转化为个人交易者能够理解、调用和持续训练的产品能力。每一个策略结论都对应清晰的逻辑、验证过程和风险边界。

## 1.2 我们为谁服务

Qell 的核心用户，是有一定交易经验和自己的操作逻辑，同时希望提升策略表达、执行和复盘能力的进阶个人交易者。

这些用户通常具有以下特征：

- 有真实交易经验和真实持仓；
- 能理解基本的市场信息与交易指标；
- 有自己的交易想法，但不会编写量化策略；
- 无法长时间盯盘，策略执行容易受情绪影响；
- 缺少系统的风险检查、模拟验证和交易复盘工具；
- 希望策略真正符合自己的收益目标、风险偏好和交易风格，而不是只获得一条通用的交易建议；
- 愿意观察策略的迭代过程，并在持续验证中形成更清晰的交易认知。

Qell 面向多资产交易场景，为不同市场中的个人交易者提供统一的策略训练与验证体验。

## 1.3 我们通过什么产品创造价值

Qell 通过以下核心产品与产品能力服务用户：

- **自然语言策略生成：** 用户用日常语言表达交易想法，由 Agent 将其转化为结构化策略；
- **Agent 量化战队：** 不同 Agent 分别承担市场研究、策略生成、风险检查、模拟训练和复盘等任务；
- **专业量化反馈：** 由专业量化团队审查 Agent 生成的策略，提出逻辑、参数、执行和风控方面的优化建议；
- **历史沙盘：** 将策略放入不同历史市场环境中，观察策略在趋势、震荡和极端行情中的表现；
- **实时模拟：** 使用当前或近实时行情持续测试策略；
- **风险检查：** 识别策略的最大回撤、风险暴露、适用环境和失效条件；
- **交易复盘：** 记录策略执行结果、失败原因和调整方向；
- **策略迭代：** 根据量化团队建议、模拟数据与复盘结果，调整策略参数、Agent 组合和风控规则；
- **迭代过程展示：** 让交易者看见每一轮修改了什么、为什么修改、验证结果如何，从而参与策略训练并反思自己的交易意图。

## 1.4 我们解决什么场景下的优先问题

Qell 主要解决以下场景：

> 用户已经形成一个交易想法，但这个想法往往仍然模糊，无法直接转化为可执行策略，也无法明确自己的真实收益目标、风险偏好和交易边界。

在这一场景中，用户最重要的优先问题不是获得更多行情信息，也不是让 AI 直接告诉自己买什么、卖什么，而是：

> **如何让交易者与 Agent 在专业量化反馈和持续数据验证中，共同把模糊意图训练成符合交易者真实期望的量化策略。**

## 1.5 Qell 的价值闭环

Qell 的完整价值闭环为：

```text
用户提出交易想法
        ↓
Agent 将想法转化为结构化策略
        ↓
专业量化团队审查策略并提出优化建议
        ↓
优化建议被结构化为 Agent 可学习的反馈
        ↓
Agent 修改策略并进入历史沙盘与实时模拟
        ↓
系统验证收益、风险、适用场景和失效条件
        ↓
交易者观察每一轮修改及其验证结果
        ↓
交易者进一步明确或修正自己的交易意图
        ↓
Agent 继续迭代，直至策略更符合用户期望
```

这个闭环不是机器单方面替用户优化策略，而是一个双向进化过程：Agent 越来越理解交易者，交易者也越来越理解自己的交易风格、市场判断和风险边界。专业量化团队的经验则逐步从人工建议沉淀为系统可以复用的评价能力。

## 1.6 用户形成正反馈的核心指标

Qell 的北极星指标是：

> **每周完成的有效策略共创闭环数。**

一次“有效策略共创闭环”由以下六个环节构成：

1. 交易者表达了具体的交易意图；
2. Agent 生成了一版可以验证的量化策略；
3. 策略获得专业量化团队或量化评价系统的优化反馈；
4. Agent 至少完成一轮策略修改和数据验证；
5. 交易者查看了策略的迭代过程；
6. 交易者确认新版本更接近自己的期望，或者进一步修正了原始意图。

该指标同时连接策略质量、Agent 学习、专业量化经验沉淀和用户认知成长，比单纯统计策略生成数、交易次数或页面停留时间更接近 Qell 的真实产品价值。

围绕北极星指标，设置三组辅助指标：

### 策略质量指标

- 用户意图匹配度；
- 量化审核通过率；
- 优化建议采纳率；
- 迭代前后的收益风险改善；
- 跨场景策略稳定性；
- 最大回撤、盈亏比和极端行情表现。

“跨场景策略稳定性”仍然重要，但它是策略质量指标，而不是唯一的北极星指标。

### 用户认知指标

- 用户查看迭代过程后的意图修正率；
- 用户是否逐渐明确自己的交易风格；
- 用户是否能够说清策略为什么有效；
- 用户是否能够识别策略的失效条件；
- 用户主动修改风险偏好和策略约束的次数。

### 健康参与指标

- 每周策略迭代次数；
- 策略迭代过程查看完成率；
- 次周继续迭代率；
- 单条策略的平均有效训练轮数；
- 用户用于策略思考、模拟和复盘的有效时间。

Qell 将健康参与定义为用户持续投入时间进行策略思考、模拟和复盘。更高的活跃度与停留时间，来自策略成长过程本身的价值，而非交易频率的简单增加。

## 1.7 如何持续改进正反馈指标

Qell 通过以下方式持续增加有效策略共创闭环：

1. 将专业量化团队的建议结构化，逐步沉淀为 Agent 可学习的评价规则和训练数据；
2. 不断增加历史市场场景与实时模拟样本；
3. 系统记录策略的成功、失败、修改和验证过程；
4. 向用户清楚展示每轮策略修改的原因和结果；
5. 引导用户确认或修正收益目标、风险偏好和交易约束；
6. 将用户接受、拒绝和修改建议的行为沉淀为交易意图画像；
7. 将模拟与真实执行的偏差沉淀为新的训练样本；
8. 将量化团队经验转化为可规模化复用的 Agent 评价与训练能力。

由此形成持续强化的产品飞轮：

```text
更多用户表达真实交易意图
→ Agent 生成策略并获得量化反馈
→ 策略完成迭代与数据验证
→ 用户观察结果并修正自己的意图
→ Agent 更理解用户，用户也更理解自己
→ 产生更多策略、反馈与认知数据
→ Qell 的策略训练与个性化能力持续提高
```

## 1.8 商业闭环

Qell 的商业模式以个人订阅和专业策略工具为起点，主要收入来源包括：

- Qell Pro 个人订阅；
- 高级历史模拟和实时模拟额度；
- 更多 Agent 和更复杂的 Agent 组合；
- 深度风险报告与策略分析；
- 多账户分析和数据导出等高级功能。

随着策略训练、风险评价和可信战绩体系不断成熟，Qell 将进一步扩展策略市场服务费、创作者工具费、策略订阅分成，以及面向机构的策略评价与风险分析 API。

# 二、竞争优势、关键战役与市场打法

## 2.1 Qell 逐步积累的竞争优势

Qell 最难被短期复制的竞争优势，不是某一个通用大模型，也不是单独的自然语言策略生成功能，而是专业量化经验、Agent 迭代数据和用户交易意图在同一系统中持续沉淀形成的共同进化能力。

### 竞争优势一：专业量化经验的系统化沉淀

专业量化团队是 Agent 的专业教练。团队对策略逻辑、参数、执行和风控的判断，被结构化为可复用的评价规则、反馈数据和训练样本。

随着系统成熟，Agent 持续学习专业量化团队判断策略的方法，使高质量的专业经验能够稳定、规模化地服务更多用户。

### 竞争优势二：完整的策略迭代与失败数据

Qell 不只记录策略赚了多少，还记录策略从第一版到最终版本的完整进化过程：

- 策略在什么环境下失败；
- 失败前出现了哪些风险信号；
- 策略产生了多大回撤；
- 是策略逻辑错误、参数问题，还是市场环境改变；
- 量化团队和不同 Agent 分别提出了什么建议；
- 用户接受、拒绝或修改了哪些建议；
- 经过调整后，问题是否真正得到改善。

成功结果容易被展示，包含专业反馈、用户选择和验证结果的策略迭代数据更难积累，也更有助于提高 Agent 的训练能力。

### 竞争优势三：用户交易意图画像

Qell 通过用户表达的策略、接受或拒绝的建议、设置的风险约束以及持续修改的方向，逐渐形成对用户真实交易偏好的理解，包括：

- 偏好趋势、套利、对冲还是均值回归；
- 可以接受多大回撤和结果波动；
- 更看重胜率、盈亏比还是收益上限；
- 偏好什么持仓周期；
- 在什么市场环境下容易改变原定计划；
- 更愿意依据哪些数据和判断方式做决策。

这种意图画像不是简单的用户标签，而是 Agent 为用户生成和优化个性化策略的重要依据。

### 竞争优势四：交易者与 Agent 共同进化的闭环

市场上的工具可能分别提供行情、策略生成、回测或跟单功能。Qell 的优势在于连接：

```text
交易意图 → Agent 生成 → 量化反馈 → 数据验证 → 用户观察 → 意图修正 → Agent 再迭代
```

用户在 Qell 中沉淀的策略版本、专业反馈、模拟记录、失败案例、选择行为和意图调整越多，Agent 对用户交易逻辑的理解就越深，用户自身对交易风格的认识也越清晰。这个双向积累过程构成 Qell 更长期的竞争壁垒。

## 2.2 增长路径：先建立证据，再扩大规模

Qell 以真实策略训练结果为增长起点，沿着“策略共创验证—小范围真实执行—策略生态扩展”的路径逐步发展。

第一阶段聚焦策略共创验证，通过真实用户、真实交易意图和多轮数据验证，建立 Agent 自我迭代与用户意图匹配的产品证据。

第二阶段将经过充分验证的策略引入小范围真实执行，持续校准模拟表现与真实市场之间的差异，并完善授权、风险控制和异常处理能力。

第三阶段以可信战绩和策略进化记录为基础，连接策略创作者、个人交易者与机构服务，形成策略订阅、创作者工具和专业 API 等规模化业务。

## 2.3 第一场关键战役：策略共创验证

Qell 的首个关键战役是：

> **通过一批真实用户和真实策略，证明专业量化反馈与 Agent 自我迭代能够帮助用户把模糊交易意图，逐步训练成更符合自身期望的量化策略。**

这场战役以以下指标衡量：

- 有效策略共创闭环数；
- 用户意图匹配度；
- 量化优化建议采纳率；
- Agent 完成有效迭代的次数；
- 用户查看迭代过程后的意图修正率；
- 用户是否更清楚自己的交易风格与风险边界；
- 跨场景策略稳定性、最大回撤和极端行情表现；
- 次周继续迭代率。

这场战役以三项成果定义成功：策略与用户意图的匹配程度得到提高，Agent 展现出持续迭代能力，用户对自身交易方式形成更清晰的理解。

## 2.4 核心市场打法

Qell 以“策略进化记录”为核心市场表达，公开展示交易者、专业量化团队与 Agent 如何共同训练出一条策略，并用可验证的迭代过程建立用户信任。

一份完整的策略进化记录包括：

1. 初始策略的交易逻辑；
2. 初始策略存在的问题；
3. 策略经历过哪些市场场景；
4. 专业量化团队和不同 Agent 分别提出了哪些意见；
5. 用户接受、拒绝或修改了哪些建议；
6. 策略参数、Agent 组合或风控规则进行了什么调整；
7. 调整后的策略与用户原始期望是否更加一致；
8. 用户在这个过程中如何重新认识自己的交易风格和风险偏好；
9. 哪些风险已经改善，哪些风险仍然无法解决。

这种“策略进化记录”既是产品结果，也是市场内容。它能够把专业量化能力和 Agent 训练能力，转化为普通用户可以理解和验证的证据。

Qell 将领先互联网产品对用户偏好的持续学习能力，应用于交易意图理解与策略个性化。健康参与度由以下产品体验驱动：

- 展示策略从第一版到当前版本的成长时间线；
- 展示不同 Agent 对策略的分析、分歧和挑战；
- 展示专业量化团队的修改建议及其依据；
- 让用户选择接受、拒绝或修改某项建议；
- 通过历史场景挑战，让用户观察策略如何成功和失败；
- 让用户逐步形成自己的交易风格档案和策略训练记录。

用户在 Qell 中投入的时间，主要用于策略思考、模拟、选择和复盘。策略不断成长、交易认知不断清晰，由此形成自然、长期的产品活跃与留存。

## 2.5 关键经营原则

Qell 将以下原则贯穿产品建设与市场发展：

- **用验证建立信任。** 每一条策略都以清晰的逻辑、模拟过程、风险边界和迭代记录作为价值证明；
- **用有效共创衡量增长。** 注册量、交易量和停留时间服务于产品价值，交易者与 Agent 是否完成真实有效的策略共创才是增长质量的核心；
- **让真实执行建立在充分验证之上。** 策略训练、风险评价和授权机制共同构成从模拟走向实盘的基础；
- **让失败成为系统资产。** 成功结果与失败场景被同等记录，共同推动 Agent 与策略评价体系进化；
- **让产品吸引力服务于用户成长。** Agent 战队、策略挑战和成长记录帮助用户理解交易，而非停留在娱乐化表达。

这些经营原则使 Qell 在追求增长的同时，始终围绕策略质量、用户认知与长期信任创造价值。

# 三、初心、使命、愿景与价值观

## 3.1 业务创办的初心

Qell 诞生于一个朴素的信念：量化交易能力不应只属于少数机构，也应服务于每一个拥有交易想法的个人。

大量交易者拥有自己的市场判断和交易想法，却难以将其转化为可以执行和验证的量化策略。编程、全天候监控以及研究、交易、工程和风控的专业协作，共同构成了个人交易者难以跨越的门槛。

Qell 的创办初心是：

> **让有交易想法但缺少技术和团队能力的个人交易者，也能拥有自己的 Agent 量化战队。**

## 3.2 初心的时代背景

传统量化交易长期存在三类门槛：

- **技术门槛：** 策略建模、代码开发、回测、数据接入和异常处理都需要专业能力；
- **团队门槛：** 完整的交易系统需要研究、策略、执行、风控和复盘等多种角色协作；
- **执行门槛：** 个人交易者容易受到时间、情绪和纪律性的影响，难以持续执行和复盘。

AI 与 Agent 的发展，使这些专业能力第一次有机会被产品化、订阅化和普及化。Qell 将个人交易者从复杂工具的使用者，转变为能够表达意图、指挥 Agent 团队并持续训练策略的创造者。

## 3.3 企业使命

Qell 的使命是：

> **Qell 不只帮助交易者生成策略，而是让交易者与 Agent 在持续验证中共同进化。**

Qell 借助专业量化团队的经验和 Agent 自我迭代系统，帮助交易者把模糊意图逐步训练成符合自身期望的量化策略。交易者通过观察每一次迭代，更清楚地理解自己的交易风格、市场判断和风险边界，并始终掌握最终决策权。

## 3.4 企业愿景

Qell 的长期愿景是：

> **成为个人交易者的 AI 量化操作系统，让过去只有机构才能拥有的策略研究、模拟训练、风险控制和持续迭代能力普及到大众。**

在这一愿景下，个人交易者可以通过自然语言指挥自己的 Agent 量化战队，调用策略研究、模拟训练、执行辅助和风险控制能力，将更多精力投入真正重要的市场判断与决策。

## 3.5 企业价值观

### 价值观一：真实胜于承诺

Qell 尊重市场的不确定性，以持续模拟、真实数据和清晰的风险边界呈现策略价值。

### 价值观二：让成败都成为资产

每一次收益、回撤、失败场景和改进过程都被完整记录，并转化为 Agent、策略和交易者共同成长的训练数据。

### 价值观三：先验证，再执行

每一条策略都先经历历史模拟、实时模拟、风险检查和失效条件分析，再进入真实执行。

### 价值观四：Agent 提供能力，用户保留最终决定权

Agent 负责生成策略、模拟市场、解释风险和提出调整建议；交易者始终掌握是否执行以及如何调整的最终决定权。

### 价值观五：易用与透明并重

Qell 用简单直观的方式呈现复杂策略，同时完整展示策略逻辑、验证过程、风险边界和失效条件。

### 价值观六：尊重差异，共同进化

每一位交易者都拥有不同的收益目标、风险偏好和交易风格。Qell 让策略逐步贴近用户的真实期望，也让交易者与 Agent 在持续验证中共同进步。

## 3.6 使命的持续演进

Qell 始终围绕“让量化能力服务更多个人交易者”这一初心前进。随着产品能力不断深化，使命的实现路径也逐渐清晰：

```text
让大众获得量化能力
→ 让大众拥有自己的 Agent 量化战队
→ 让交易想法变成可验证、可复盘的策略
→ 让交易者与 Agent 在持续验证中共同进化
```

从量化能力普及，到 Agent 战队协作，再到交易者与 Agent 共同进化，Qell 持续拓展初心的实现方式，并保持价值内核的一致。

## 3.7 初心如何穿越周期

金融市场有周期，技术发展有周期，企业成长同样有周期。Qell 以初心和使命作为长期战略坐标，在产品、增长与商业化选择中持续回答同一个问题：

> **这项工作是否能够帮助 Agent 更好地理解交易者、帮助交易者更好地理解自己，并形成一次真实有效的策略共创？**

这一标准帮助 Qell 将资源持续投入专业量化经验沉淀、Agent 自我迭代、用户意图理解和策略共创体验，在市场波动与增长压力中保持长期方向。
