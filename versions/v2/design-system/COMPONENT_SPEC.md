# V2 Component and Composition Specification

## System Principle

Components share tokens, behavior, and edge discipline. Pages do **not** share a generic dashboard composition.

## Core Components

### App Shell

- fixed 76px desktop header / 66px mobile header;
- QELL source logo asset;
- four global destinations;
- paper-demo status;
- contextual five-stage journey rail.

### Agent Identity Plate

- institution-style typographic identity;
- no portrait, particle, role geometry, or avatar placeholder;
- code + role + Chinese name + Latin registration + thesis + metrics + factors;
- compact, regular, and wide densities;
- selected state uses semantic accent and material lift.

### Work Surface

- only the dominant task surface receives a full quiet frame and long shadow;
- secondary information uses open alignment, top rules, or inset rails;
- nested framing is allowed only when parent and child have different task roles.

### Action

- one acid primary action per decision area;
- secondary is acid outline;
- quiet is neutral outline;
- text action is reserved for low-priority navigation;
- disabled state must explain its requirement nearby.

### Signal Bar

- shows a calibrated score, never decorative progress;
- acid = active/positive;
- cyan = data/structure;
- ember = execution/caution;
- rose = risk/negative;
- steel = neutral quantitative intelligence.

### Data Rule

- one-line label/value instrument;
- horizontal rule is structural and continuous;
- no fake table grid when a single comparison row is sufficient.

### Charts

- chart area appears only when it supports a judgment;
- runtime market chart is subordinate to the Agent decision record;
- result curve is the dominant evidence surface;
- color and tooltip styling use system tokens;
- implicit entrance animation is disabled for deterministic review.

## Page-specific Composition

| Page | Dominant composition |
|---|---|
| Home | editorial proposition + stacked team specimen |
| Marketplace | curatorial mosaic + selected-team dock |
| Agent detail | registration profile + evidence scoreboard |
| Team | three strategy desks + readiness instrument |
| Events | scenario shelf + selected-event brief |
| Runtime | market context + dominant decision theater + team rail |
| Result | oversized return + evidence curve + post-mortem |
| Leaderboard | ranking field + selected-team profile + progression |

## Prohibited Patterns

- purple-family colors or blue-purple gradients;
- rounded card grids;
- glass surfaces;
- particle portraits;
- Web3 casino reward styling;
- large decorative glows;
- broken/corner/circuit fine lines;
- repeated radar and ring charts;
- unverifiable chain-of-thought narration.
