# Qell 产品介绍 V5：界面文案分析

来源：`qell_产品介绍-v5.pptx`，共 23 页。

## 1. 可继承的产品语言

PPT 对产品的描述围绕六个连续动作展开：

1. 表达交易意图；
2. 召集交易智能体；
3. 组建专属量化战队；
4. 进入历史沙盘推演；
5. 查看策略归因与策略 DNA；
6. 让策略表现被排名、比较与验证。

建议进入产品界面的核心术语：

- 专属量化战队
- 交易意图
- 协同分数
- 历史沙盘推演
- 历史事件训练场
- 策略评估
- 策略 DNA
- 公开、可比较、可验证
- 复盘归因
- 风险、风格、执行与稳定性

## 2. PPT 的表达特征

- 标题使用强动作动词，例如“组建”“召集”“推演”“训练”“验证”。
- 大标题通常只传达一个变化或一个结果。
- 产品能力通过“用户动作 + 系统回应”展开，适合转化为页面流程。
- 叙事从交易意图逐步进入策略资产，具有明确的阶段感。
- 数字主要承担证据与结果角色，适合放入状态栏和结算页。

## 4. 语气规范

- 主标题：结果导向、短句、单一判断。
- 副标题：解释用户动作、证据范围或风险边界。
- CTA：使用明确动作，避免抽象口号。
- 数据标签：使用产品事实，不使用情绪化评价。
- 风险提示：明确模拟属性、公开信号来源与非投资建议边界。

## 5. 文案来源标记

- `DIRECT`：PPT 原文可直接进入 UI。
- `ADAPTED`：保留核心含义，为界面长度压缩。
- `NEW`：依据 PPT 术语和产品流程重新创作。
