# V2 第一轮修改规格

## 目标

- 接入 Qell 产品介绍 V5 的语言体系。
- 移除标题中的对立式句法。
- 建立可控的响应式标题断行系统。
- 为主要 CTA 增加克制的表面折射反馈。
- 为历史事件卡片增加与行情方向相关的轻量动态。
- 增加“当前运行 Agent 数量”，并明确其模拟会话属性。

## 文案

- 标题以直接陈述为主，每个标题只保留一个判断。
- PPT 中的“专属量化战队、协同分数、历史沙盘推演、策略 DNA、公开可比较可验证”作为核心词汇。
- 正文继续保留模拟、公开信号和非投资建议边界。

## 响应式标题

- 标题内容拆分为语义完整的短语。
- 桌面端与移动端分别提供人工校准的行结构。
- `text-wrap: balance` 只承担自动平衡兜底。
- 字号使用有界 `clamp()`，避免用持续缩小字体解决断行。
- 移动端允许 2–3 行，保证每一行都是完整语义单元。

## Surface Refraction

- 仅应用于主要 CTA 和选中的关键操作。
- Hover 使用指针位置驱动的径向折射光。
- Press 使用一次低透明度扩散波。
- 次要按钮保留边框和亮度反馈。
- 触摸设备提供按压反馈，不依赖 Hover。
- `prefers-reduced-motion` 下关闭位移动画与持续波纹。

## Historical Scenario Presence

- 每张历史事件卡片展示“模拟运行中的 Agent 数量”。
- Demo 使用固定基数与小范围周期变化，避免误导为真实用户或真实资金交易数据。
- 数字每 8–15 秒更新一次，以淡入淡出完成变化。
- 下跌事件使用 Rose 方向光场，上涨事件使用 Acid，结构性事件使用 Cyan。
- 动态层保持低对比，文字与事件信息维持最高视觉权重。

## 验证范围

- 视口：1440、1280、1024、768、430、390、360。
- 核心交互：CTA、筛选、事件卡片、Agent 选择、组队、模拟、结算、排行榜。
- 无水平溢出。
- 键盘焦点清晰。
- 减少动态效果模式可用。
- 构建通过且无控制台错误。
