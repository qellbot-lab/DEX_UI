## Design Context

### Users

QELL 中文版面向桌面端 Agent 交易产品用户。用户需要发现智能体、组建交易战队、选择历史事件、观察模拟、理解决策并复盘结果。主要使用状态是专注、分析和验证，不是休闲浏览。

### Brand Personality

品牌人格：克制、精确、有后果感。

- 克制：状态色稀少，视觉效果服从信息。
- 精确：数据、对齐、术语、交互状态和组件行为都有一致规则。
- 有后果感：交易动作、风险和模拟结果需要显得真实、严肃、值得判断。

### Aesthetic Direction

方向：Quiet Trading Infrastructure / 静默交易基础设施。

采用深色桌面产品主题、编辑式排版、大面积无框暗场、少量高价值面板和明确的数据层级。QELL 网站与 `QELL_Frontend_Art_Pack` 用于视觉体系参考；`中文版UI草稿` 是页面内容和流程来源。

明确禁止：Purple、Violet、Magenta、Indigo、Lavender、Lilac、Mauve、蓝紫渐变、紫绿对撞、赛博 HUD、Web3 Casino、黑客终端、满屏发光、随机电路线、装饰 Sparkline、重复六边形、通用圆环评分、所有页面默认雷达图、卡片嵌套卡片，以及由图片模型直接生成完整 UI。

### Design Principles

1. 排版先于图形：标题、数字、列宽、行距和留白建立高级感。
2. 颜色是动词：Acid 表示操作与 Live，Cyan 表示数据，Ember 表示执行与注意，Rose 表示风险；Quant 使用中性 Steel。
3. 无框优先：先用空间与对齐分组，只有可操作或拥有独立状态的内容使用完整边框。
4. 一屏一个判断：每个视口最多一个主视觉、一个主操作和一张复杂图表。
5. 效果必须可解释：粒子、连线、光晕和动画只能表达身份、关系或真实运行状态。
6. HTML 先于图片：完整页面由真实 HTML/CSS 实现并截图；ImageGen 仅生成独立 Agent 身份资产。

### Initial Delivery Scope

- 第一阶段：1440px 桌面端 Foundations 与 Component Lab。
- 粒子 Agent 每个视口最多出现一次。
- 中文原型使用系统中文字体栈，生产前确定并引入已授权中文字体。
- 所有边框为清晰、连续、贴合像素网格的 1 CSS px 实线。
