# QELL UI Version Registry

This directory separates frozen historical work from the active redesign.

- `v1/` — immutable archive of the first complete UI direction. The source folder was named `design-system/v3`, but it is treated as product iteration **V1**.
- `v2/` — completed second-version high-fidelity frontend demo, design system, research evidence, 17 final preview captures, and three QA audit rounds.

The original top-level source folders remain in place so existing local links continue to work.
